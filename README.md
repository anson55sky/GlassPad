# GlassPad

macOS 原生 Launchpad 替代工具，采用 Liquid Glass 美学，全面支持无限屏画布、实时桌面壁纸捕获。

**本仓库为公开发布页**：只放版本标记、更新日志与安装包，**不含任何源码**。

## 下载 / Download

- **官方站点（下载 / 更新日志）：[glasspad.pocketbay.app](https://glasspad.pocketbay.app/)**
- **最新版（本仓库）：[GlassPad-1.0.539.dmg](https://github.com/anson55sky/GlassPad/releases/download/v1.0.539/GlassPad-1.0.539.dmg)**
- 所有历史版本见 [Releases](https://github.com/anson55sky/GlassPad/releases)

## 关于四指手势（无需额外设置）

**从 v1.0.306 起，GlassPad 与系统手势共存，不再需要你在系统设置里关闭任何触控板手势。**

- 四指捏合（拇指 + 三指）只会唤起 GlassPad，系统的「App」面板不会常驻弹出。
- 玻璃板关闭后，四指张开仍保留系统原生的「显示桌面」行为。
- 「设置 → 触控板 → 更多手势」里的 **App** 与 **显示桌面** 两个开关可以**原样开着**，互不影响。

> GlassPad **从不写入、也不删除你的任何系统偏好**。状态栏图标右键菜单里有「打开系统设置」的直达入口，点一下即可跳转。

## 安装 / Install

1. 下载 `.dmg`，将 **GlassPad** 拖入「应用程序」。
2. 首次打开若被 Gatekeeper 拦截：右键 App →「打开」，或在 **系统设置 → 隐私与安全性** 中点击「仍要打开」。
   （当前为自签名证书、尚未公证 Notarize，属正常提示。）
3. 首次启动后请授予**辅助功能**权限 —— 四指手势接管依赖它。
4. **壁纸权限说明**：静态图片壁纸无需任何权限；动态/Aerials 壁纸的高保真实时捕获可能需要「完全磁盘访问」，未授权时自动降级为系统资源，不会空白。

### v1.0.539 · 修复新装应用图标显示成占位模板 `[REQUIRED]`

- **问题**：新安装/未索引的应用在 GlassPad 里显示成占位图。1.0.536 及之前是**禁止符号**（白方块 + 灰色圆圈斜杠），1.0.538 变成**通用网格模板**（白方块 + 浅灰网格 + 中心准星），图标依然不显示。

### v1.0.310 · 磁吸翻页 + 模糊档位 + 连续滚动开合修复 `[REQUIRED]`

**⚠️ 已在用的用户请重新授权一次辅助功能权限** —— 系统设置 → 隐私与安全性 → 辅助功能，把 GlassPad 重新打开一次。

- **磁吸：一次手势恒等于一页**（此前最多翻两页）。关键发现不是判定更聪明，而是 **Buho 的条带物理上就划不远** —— 跟手上限在四分之一页宽左右，怎么划都划不出「正在去第二页」的中间态，这才是磁吸感的来源。
  - 双指页内跟手：1:1 到 25% 页宽 → 渐进阻尼 → **渐近 16% 页宽（1.06 列）**。不是硬墙，是有墙但没墙挡着。
  - 翻页阈值 25% 页宽（378px）→ **8%（121px）**；四条翻页判定（双指/鼠标 × 主网格/文件夹）此前是**三套规则并存**，文件夹用固定 40px 阈值（页宽的 3.3%），同一手势在两处手感完全对不上，现已统一并硬钳 ±1。
- **位置门槛**：末速上限 6000px/s，光惯性投影就有 1920px —— 抬手指只走了 5%（61px）也会被算成 85% 而提交翻页。实测 44 次提交里 10 次（23%）属于这种越权，落定动画要在 0.3s 内跑完剩下 95% 页宽，其中 9 次变成 Q-jog 白弹（就是「非常卡顿」）。现在位移不过 12.5% 页宽时速度没有接管权；实测主网格 37 次提交拦下 7 次（19%）误翻、真翻页 0 误伤。
- **滚轮节流不再吞掉滚动累积**：被节流丢掉的那一下，翻页和它的滚动增量一起没了，闩锁却已上锁 —— 表现是「翻页一次后再快速翻第二次，过渡效果基本没了」，第二下不是没动画，是根本没发生。
- **文件夹两页之间有了 60pt 缝隙**：此前一个值同时当「一页多宽」和「翻一页走多远」，两者绑死导致缝隙只能是 0。内容宽没动，**静止观感零变化**。
- **模糊强度改 5 档**（关闭 / 轻度 / 中度 / 强度 / 超强），**松手才生效**。此前每拖 1% 就触发一次 3024×1964 全屏高斯模糊（实测 ~148ms），且合并循环会无条件发布过期结果 —— 面板落后滑块 250ms 以上、中途还会倒退；每次发布又触发整块面板重渲染，SwiftUI 一直忙，`ScrollView` 手势抢不到时间，于是**拖滑块变成滚动面板**。两个症状同一个根因。滑块本体改用系统原生 `Slider`，档位行等分排列、零绝对定位。
- **连续滚动模式开关面板「整层从右边挤进来」已修**：`fullW = max(rootW, padFrame.width)` 里的 `padFrame` 取的是**全局** frame，而它挂在挂了 `.scaleEffect` 的祖先之下，开合期间被撑大 1512→1587，ScrollView 比内容宽 75pt 导致内容居中右移。改成只用本地尺寸。**静止观感逐像素不变。**
- **鼠标拖拽保持 1:1**，不受双指阻尼影响 —— 鼠标是位置型输入，要能看着条带精确停在某两列之间再松手。

  认定「这是一个新程序」而作废既有授权。表现为：更新后四指手势接管静默失效。
  现在签名锚定 bundle 标识，**授权跨更新不再丢失**。
- **拇指先下再三指捏合不再误唤醒**：对齐 Buho —— 只有四指同时捏合才触发。
- 文件夹开合帧率 38.6 → 63 fps；点击到起跳 72.1 → 20.5 ms；首次召唤 717 → 459 ms。
- 修复刘海遮挡下文件夹名称被裁掉的问题。
- 已知未解决：文件夹底板玻璃在「设置」窗口打开时会消失（原生玻璃跟随窗口焦点）。
